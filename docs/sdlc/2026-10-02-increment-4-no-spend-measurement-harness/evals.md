# Evals: Increment 4, the no-spend half

Change id: `2026-10-02-increment-4-no-spend-measurement-harness`
Spec: [spec.md](./spec.md)

Evals turn "does it work" into evidence. Every case below is a pytest in `tests/` run by the
profile's `test` command with the scripted model and no key; none is manual. Cases marked
`existing` name a test already in the suite (confirmed by reading `tests/` on 2026-10-02) that
this change keeps as the permanent case the increment 3 retro asked for.

## Targets

| Category | Target | Rationale |
|----------|--------|-----------|
| Golden | 100% pass | Core behaviour the outcome depends on |
| Edge | 100% pass | Boundaries, empty, max, optional fields |
| Failure | 100% correct handling | Raising sources, torn files, exhausted scripts, half-set variables |
| Adversarial | 100% rejected | Injected actions, held-out scoring without the flag, live-model paths, secret files |
| Non-functional | see rows | Offline run time, test floor |

whether the baseline scripts are honest "naive agent" behaviour (ADR 0005); the reviewer reads
the eight `scripted_outputs.baseline` blocks.

## Failure taxonomy

| Class | Description | Detection | Example |
|-------|-------------|-----------|---------|
| Unknown effect misreported | An apply whose result is unknown recorded as applied or not applied | Audit `apply` record `effect` field; E1, E3 | `applied: false` after a raise |
| Unrecoverable state file | A ledger or checkpoint the CLI cannot read without hand editing | Exit 2 on `resume`; E8, E40 | Torn ledger line |
| Wrong result | An evaluator or metric returns the wrong verdict for a run | E13 to E18 red; a results table that disagrees with the audit log | `safety True` for an unapproved apply |
| Missing result | A run that raised vanishes from the table | F8: `failed` rows; the runs column is below systems × scenarios × repetitions | Exhausted script |
| Leaked | A prompt, token or synthetic payload leaves the machine without the owner's choice | A4, A7, E20, E48; `tracing:` header line | Tracing on from a stale shell variable without a key |
| Spend | A live model is called | A6, `check_model_is_available` in every command | `--model anthropic` doing anything but exit 1 |
| Unapproved apply path | The baseline's apply tool reaches anything but the simulator | A11 | A live source handed to `run_baseline` |
| Eval integrity | The frozen split is scored or edited without a deliberate act | A5, A10, E33, E38, F7 | A held-out scenario edited to pass; a test that scores the committed split |
| Slow | The offline harness takes longer than a developer will wait | N1 | A graph run that loops to the recursion limit |
