# Evals: wire the live Anthropic model path

Change id: `2026-10-05-wire-live-anthropic-model-path`
Spec: [spec.md](./spec.md)

Every case runs on the scripted model or a stub, with the network guard on. The one case that
reaches a model (E27) is opt-in and is listed under "Not verified" until the owner runs it. No
case prices the real API; the price table's numbers are checked for shape, and the owner checks
them against the Anthropic pricing page at Ship (brief D5). Ids E2 and E36 are unused: the
revision merged them into E1 and E7 to stay inside the tier-2 case limit.

## Targets

| Category | Target | Rationale |
|----------|--------|-----------|
| Golden | 100% pass | Core behaviour the outcome depends on |
| Edge | 100% pass | Boundaries, empty usage, override naming, unpriced ids |
| Failure | 100% correct handling | Missing key, bad reply, API error, skipped smoke test |
| Adversarial | 100% rejected | Key leakage, network reach, fallback to the app key, secret in CI |
| Non-functional | see rows | Cost per run printed, suite stays offline |

## Non-functional

| ID | Measure | Target | How measured |
|----|---------|--------|--------------|
| N1 | Connection attempts during `pytest -q` with `--model scripted` paths | 0 outside loopback | The guard raises on any; a passing suite is the measurement (E23 proves the guard bites) |
| N2 | Cost per run printed for a live run | Present for every priced model id, `n/a` otherwise, never a wrong number | E12, E14, E15 |
| N3 | Spend before `--yes` | $0: no client constructed before the guard, with priced or unpriced ids | E16, E38 (constructor spy) |

## Failure taxonomy

| Class | Description | Detection | Example |
|-------|-------------|-----------|---------|
| Wrong result | Cost or token count differs from the reply's usage | `cost_usd` and `usage_action` unit tests; the table's spread against `--json` | Cache write counted twice |
| Missing result | A live call recorded with zero tokens, or an estimate that cannot be priced | Table shows zeros; E9 covers the absent-usage shape (model id falls back to the configured id); E38 covers the unpriced estimate | SDK changes `usage_metadata` keys |
| Leaked | A key value in stdout, stderr, state, audit or a trace | E25 asserts stdout empty and stderr names only the variable; the guard keeps tests offline | Error message quoting the environment |
| Unauthorised spend | A model call before `--yes`, or in CI's default job | N3, E28, E29 | A test importing the live factory with a shell key |
| Unrecoverable | API error inside a node ends the run | Exit 2 names the type; eval row `failed`; `resume` continues from the checkpoint | 529 overloaded after SDK retries |
| Slow | A live call far above the design's latency | `latency_ms` spread in the table | Cache miss on every call |
